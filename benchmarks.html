Benchmark 03 · Motion & Animation Codecs

Animated GIF vs Animated WebP vs H.264 MP4 vs VP9 WebM

Legacy GIF uses 1987 LZW dictionary compression limited to 256 colors per frame. Replacing inline GIFs with muted, looping <video autoplay loop muted playsinline> elements cuts payload by 85%–92% (GIF vs MP4 vs WebM comparison).

Container / Codec 10s 720p Clip Size Color Depth Payload Savings Typical CLI / Tooling
Legacy Animated GIF 14.8 MB 8-bit (256 Colors) Baseline (0%) gifsicle / FFmpeg palettegen
Animated WebP 3.9 MB 24-bit + 8-bit Alpha -73.6% Smaller gif2webp / img2webp

Benchmark 04 · Metadata & Redaction Hygiene

EXIF Privacy & Irreversible Screenshot Redaction

Always strip EXIF GPS tags before publishing user-generated images (exiftool -all= or client-side tools like Vexelloom EXIF Scrubber), and avoid translucent markup highlighters when redacting sensitive screenshots—solid canvas pixel replacement prevents contrast-recovery leaks (redaction security breakdown).
